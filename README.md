## 📍 The Process

siteSprout was built to remove repetitive setup work when starting new frontend projects.

During my full-stack development journey, I often needed a simple, clean frontend scaffold to quickly test ideas and connect to existing backend services like Supabase. I couldn’t find something that felt lightweight, flexible, and easy to customize, so I decided to build my own.

At first, it started as a personal tool. But over time, it evolved into a reusable frontend scaffold that anyone can plug into and adapt to their needs.

The core idea became simplicity through structure — instead of rebuilding the same UI patterns again and again, everything is driven through a single `data.tsx` file. This allows you to quickly customize content, layout, and links without touching the underlying architecture.

It’s designed for static or content-driven websites, where companies can easily showcase information, link to existing products, or integrate external booking systems without unnecessary complexity, while still offering a clean gateway to extend into backend functionality when needed.

## 🚦 Running the Project

### 1. Clone or Fork this repo

git clone https://github.com/rajan-daniel/siteSprout.git

Or click **“Fork”** on GitHub to create your own copy.

---

### 2. Install dependencies

npm install
or yarn
or pnpm

---

### 3. Customize

Edit `data.tsx` to update content, layout, and structure.

Replace assets in the `public/` folder (images, logos, icons, etc.).

Keeping the same file names and similar asset sizes will help ensure the best results.

---

### 4. Run locally

npm run dev

Open:
http://localhost:5173

---

### 5. Build

npm run build

Deploy the `dist/` folder to Vercel, Netlify, or any hosting platform.
